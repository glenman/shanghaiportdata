# 知识库原始数据文件持久化目录 (Knowledge Base Data Directory)

本目录为应用的标准数据持久化目录：`data/knowledge/`。

### 使用说明：
1. **存放您的数据文件**：
   您可以直接将准备好的数据文件（例如 3 个结构化 `.json` 文件、`.txt`、`.md` 或 `.csv` 文件）上传或放置于此目录。
2. **自动加载机制**：
   - 服务端启动时会自动扫描本目录下的所有文件并构建知识库索引与向量切片。
   - 在前端管理界面（【知识库管理】弹窗）中，点击【🔄 重新扫描本地目录】按钮，即可无需重启一键热加载最新文件。
3. **支持格式**：
   - **JSON (`.json`)**：支持海港赛程、比赛结果、球员数据或统计阵列，支持字段精准检索与全量语义问答。
   - **Markdown (`.md`)** 与 **纯文本 (`.txt`)**：支持球队历史、重要战报与人物传记。
   - **CSV (`.csv`)**：支持表格数据自动分块。
